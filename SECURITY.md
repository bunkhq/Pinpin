# Security policy

Pinpin uses Screen Recording and Accessibility permissions, so security reports matter.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub security advisories](https://github.com/bunkhq/Pinpin/security/advisories/new).

Include steps to reproduce and the Pinpin and macOS versions you tested. You'll get a reply as soon as possible, and credit in the release notes if you want it.

## Supported versions

Only the [latest release](https://github.com/bunkhq/Pinpin/releases/latest) gets security fixes.
